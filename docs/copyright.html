Game Details

Quantum Star SE is written in the PHP language, with data stored and retrieved using either the MySQL or PostgreSQL Database Management Systems which use SQL (Simplified Query Language). Javascript is used on a limited basis.

The official website for the project which will eventually also host several games, can be found at http://www.quantum-star.com. Our forums are also located here for any questions or feedback users may wish to share.

Quantum Star SE 2.3.0 is currently in Beta.
